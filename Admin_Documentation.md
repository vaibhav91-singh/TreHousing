# TRE Housing Publications - Admin Operation Guide

This document is a complete guide to operating the Django Admin Panel for the TRE Housing Publications website. It explains **where to add data** in the admin dashboard and **where that data reflects** on the frontend website.

---

## 1. Job Vacancies & Updates (Career & Exam Hub)

### Job Vacancies
**Where to Add:** 
- Go to Admin Panel -> `Core` -> `Job Vacancies`.
- Click **Add Job Vacancy**.
- **Fields to Fill:** Title, Organization, Eligibility, Form Fee, Apply Date, Last Date, Official Website Link, Status (Active/Inactive), Apply Link, Category Badge (e.g. UPSC), Vacancy Count, Qualification, and Job Type (GOVT/PRIVATE).
**Where it Reflects:** 
- **Website Location:** `/job` (Career & Exam Hub).
- **Appearance:** Shows up as colorful Job Cards. It automatically filters into "Government Jobs" or "Private Jobs" based on the `Job Type` you selected.

### Recent Updates
**Where to Add:** 
- Go to Admin Panel -> `Core` -> `Recent Updates`.
- Click **Add Recent Update**.
- **Fields to Fill:** Title (e.g. BPSC Result Declared), Description, and Link.
**Where it Reflects:** 
- **Website Location:** Bottom section of the `/job` (Career & Exam Hub) page under the "Recent Updates" list.

## 2. Study Materials

### Study Material System
This is structured in a 3-level hierarchy: Exams -> Subjects -> Documents.

**Where to Add:** 
1. **1. Study Material Exams:** Add the main exam category (e.g., UPSC, SSC).
2. **2. Study Material Subjects:** Add a subject and link it to the Exam (e.g., Modern History linked to UPSC).
3. **3. Study Material Documents:** Add the actual study notes. Link it to the Subject, provide a Title, and paste the Google Drive/AWS S3 `file_link`.

**Where it Reflects:** 
- **Website Location:** `/study-materials` (Study Materials Page).
- **Appearance:** Students will see an accordion or list of Exams. Clicking an Exam shows its Subjects, and clicking a Subject reveals the download/view links for the PDF Documents.

---

## 3. Topic-Wise Quiz System

This is structured in a 4-level hierarchy. It allows students to take MCQ tests based on specific topics.

**Where to Add:** 
1. **1. Topic-wise Exams:** Add the main exam category (e.g., SSC CGL).
2. **2. Topic-wise Subjects:** Link a subject to the Exam (e.g., Geography).
3. **3. Topic Names:** Link a topic to the Subject (e.g., Indian Geography).
   - *Pro Tip (Bulk Upload):* You can paste a JSON array in the `bulk_upload_json` field to automatically create 100s of questions instantly.
4. **4. Topic-wise Questions:** You can manually add questions here, provide 4 options (A,B,C,D), select the correct option, and add an explanation.

**Where it Reflects:** 
- **Website Location:** `/quiz` (Topic Wise Quiz Page).
- **Appearance:** Students navigate through Exam -> Subject -> Topic to start an interactive MCQ quiz.

---

## 4. Full-Length Mock Tests (Test Series)

**Where to Add:** 
1. **Quizzes:** Go to Admin -> `Core` -> `Quizzes`. Add a Quiz (e.g., UPSC Prelims Mock 1).
2. **Questions:** Go to Admin -> `Core` -> `Questions`. Add a question text and link it to the Quiz.
3. **Choices:** Go to Admin -> `Core` -> `Choices`. Add options for the question and mark `is_correct` as true for the right answer.

**Where it Reflects:** 
- **Website Location:** `/testseries` (Test Series Page).
- **Appearance:** Students can enroll and take full-length mock tests.

---

## 5. Past Papers (Solved Papers & Answer Keys)

**Where to Add:** 
- Go to Admin Panel -> `Core` -> `Past Papers & Answer Keys` (SolvedPaper model).
- Click **Add Past Paper**.
- **Fields to Fill:** Title, Year, Paper Link (Google Drive), Answer Key Link (Optional), and you can optionally link it to a Mock Test.

**Where it Reflects:** 
- **Website Location:** `/solved-papers` or the respective subject's resource page.
- **Appearance:** A list or table where students can download previous year question papers and official answer keys.

---

## 6. Core Courses & Syllabus

**Where to Add:** 
1. **Courses:** Add main courses (e.g., BPSC Foundation). Upload a Banner Image.
2. **Subjects:** Add subjects under the course. You can upload a Subject PDF link, Total Questions, and Total Marks.
3. **Exam Patterns & Content:** Define the exam duration, topics, and marks distribution.
4. **Syllabus / PYQs:** Upload official Syllabus PDFs and Previous Year Question PDFs.

**Where it Reflects:** 
- **Website Location:** Homepage (`/`) course listings and individual Course Detail pages.
- **Appearance:** Shows as course cards with detailed syllabus timelines, exam patterns, and downloadable PDFs on the frontend.
